# Marks & Grade Calculator

A simple beginner-level project made with HTML, CSS, and JavaScript.

## Features
- Enter a subject name
- Enter total and obtained marks
- Calculate percentage automatically
- Show grade based on the percentage

## Grading System
- 85–100%: A
- 71–84%: B
- 61–70%: C
- 50–60%: D
- Below 50%: F

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enter your marks and click **Calculate**.
4. Or you can see the link in Description
